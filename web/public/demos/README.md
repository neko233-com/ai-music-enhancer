# Project demo audio

These six examples are included for offline functional demonstrations.
They are project demos, not AudioSR author benchmarks.

- `voice-1`: original Chinese text, Microsoft Huihui system speech synthesis.
- `voice-2`: original English text, Microsoft Zira system speech synthesis.
- `music-1`, `music-2`: original mathematically synthesized compositions.
- `vocal-music-1`: **Auld Lang Syne**, Frank C. Stanley, 1910. Singing with accompaniment, excerpt 30–42 seconds. Source: https://commons.wikimedia.org/wiki/File:Auld_Lang_Syne.ogg (public-domain composition and historical recording; source page also records click removal by Adam Cuerden).
- `vocal-music-2`: **Daisy Bell**, Edward M. Favor, 1894; composition Harry Dacre. Singing with accompaniment, excerpt 20–32 seconds. Source: https://commons.wikimedia.org/wiki/File:Daisy_Bell_sung_by_Edward_M._Favor.ogg (public-domain composition and historical recording).

The first four are generated by `scripts/generate-demos.ps1` and `scripts/generate-demos.py`.
They are deliberately bandwidth-limited to 5.5–6 kHz for restoration testing.
The final two are imported by `scripts/import-vocal-demos.py`, resampled to 24 kHz with 20 ms fades and peak normalization. Source hashes and excerpt positions are in `manifest.json`.
Original project text, compositions and the first four demo files use the project's MIT license. The final two retain public-domain status. No speech synthesis models are redistributed.
